# Customer Intelligence & CRM Analytics Platform

Plataforma de Inteligência de Clientes e Análise de CRM

## Sobre o Projeto

O **Customer Intelligence & CRM Analytics Platform** é um projeto de portfólio voltado ao desenvolvimento de uma plataforma analítica para integração, processamento e análise de dados de clientes, vendas, marketing e atendimento.

O projeto simula uma empresa fictícia de varejo omnichannel, utilizando dados sintéticos autorais para representar cenários e desafios encontrados em ambientes corporativos.

A solução busca transformar dados operacionais em informações estratégicas, apoiando a tomada de decisões relacionadas à aquisição, conversão, retenção, satisfação e fidelização de clientes.

## Objetivos

- Desenvolver uma arquitetura de dados estruturada e escalável.
- Criar dados sintéticos com características realistas.
- Integrar diferentes fontes de dados por meio de arquivos e APIs REST.
- Implementar processos de ETL e integração.
- Construir um Data Warehouse com modelagem dimensional.
- Desenvolver indicadores de desempenho comercial e relacionamento.
- Analisar o comportamento e a segmentação de clientes.
- Construir dashboards interativos.
- Aplicar técnicas de análise estatística e Machine Learning.
- Desenvolver uma API para disponibilização de informações analíticas.

## Escopo Analítico

O projeto contemplará as seguintes áreas:

| Área | Principais indicadores e análises |
|---|---|
| Vendas | Receita, ticket médio, recompra e conversão |
| Funil Comercial | Leads, oportunidades e taxas de conversão |
| CRM | Segmentação, RFM e comportamento dos clientes |
| Retenção | Churn, retenção, LTV e Cohort Analysis |
| Experiência do Cliente | NPS, CSAT e CES |
| Marketing | CAC, ROI, ROAS e desempenho de campanhas |
| Data Science | Segmentação e previsão de comportamento |

## Arquitetura da Solução

A arquitetura seguirá o fluxo:

**Fontes de Dados → RAW → STG → ODS → Data Warehouse → Analytics / BI / Machine Learning**

As fontes incluirão dados sintéticos, arquivos estruturados e integrações com APIs REST.
